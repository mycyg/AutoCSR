# 疫苗 CSR 模板

适用于：预防性 + 治疗性疫苗的 I/II/III 期试验。

预设要点：
- 指导原则：vaccine (ICH E3 + 疫苗特化)
- 免疫原性：GMT (geometric mean titer) / SCR (≥4 倍升高) / SCT (血清保护)
- 效力：VE = 1 − IRR；分主要 + 次要 (重症 + 住院) case definitions
- 持久性：6/12/24 月随访 + GMT 衰减曲线
- 反应原性：solicited 7 天日记 (局部 + 全身) + unsolicited 28 天
- AESI：心肌炎/格林-巴利/过敏反应/血栓；背景率比对

使用：「新建项目」下拉选「疫苗 CSR」或调 `POST /api/projects/from_sample/vaccine`。
